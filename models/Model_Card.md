# 模型说明

> GitHub 公开版说明：本仓库保留模型结构、配置和研究结果，二进制权重不进入 Git 历史。下文“随包”指原正式代码包；公开版权重的取得与放置方法见 [`docs/resources.md`](../docs/resources.md)。

版本：GPR84全量拟合2026-10-01_v1；主种子20261001。两个20261002/03模型用于预定种子敏感性分析，主结果使用20261001模型。随包正式权重对应已有目录筛选与外部评价。

`train.py`可按固定配置在新目录重拟合，`screen.py`/`predict.py --model-dir`可加载该目录；`main.py --workflow full`自动衔接。新训练模型不自动替换上述归档模型，其筛选表记录独立重拟合版本及运行版本。本卡的历史评价指标对应10月1日归档权重，不自动转移到新模型。

## 文件与结构

`model_20261001.pt`、`model_20261002.pt`、`model_20261003.pt`各34,868,201字节，为完整模型state_dict。`pretrained/chemeleon_mp.pt`为原始编码器起点，34,859,448字节；训练/推理入口通过其架构元数据构建网络，正式推理随即严格加载相应完整微调权重。预训练来源：Zenodo 15460715（10.5281/zenodo.15460715）。相关来源记录和原许可见`data/pretraining/`与`licenses/`。

Chemprop 2.2.0 BondMessagePassing：原子/键特征72/14，d_h=2048，depth=6，bias=False，activation=relu，dropout=0，undirected=False。平均池化后无仿射LayerNorm（eps=1e-5）接2048→1线性头。编码器8,714,240参数。

训练为277实验内分子单位/248输入图，阈值为人GPR84拮抗功能实验IC50≤1 µM。Adam lr=1e-4、30 epoch、batch16、weight_decay=0，分别裁剪编码器和头梯度范数5；相同输入图跨实验重复计权降权。种子与偏移在`configs/submission.json`。最后不足16单位的批损失仍除以固定batch_size，与原实现一致。全量拟合没有持出验证集，最终epoch固定，不按外部数据早停或调参。

## 输入与输出

输入为标准化SMILES；图包含已指定的原子手性，未指定立体或轴手性保持未知。目录预处理、已知/隔离身份排除、结构范围与规范有立体图去重见README。输出为原始logit及本次输入内排名，用于提出候选假设。logit为无量纲排序分数，未校准为活性概率，也不对应IC50或结合亲和力。

正式提名：主种子logit降序、同分按ID；前1%上限1000，取不同无立体Murcko骨架，最多10项。最近强效训练单位计数Morgan Tanimoto为独立相似性参照；另两种子的排名差异与近邻相似度未校准成置信区间或可靠性阈值。

## 已有证据

- 内部开发：整篇文献留出、训练侧连接图重叠排除，5主要实验前20%预算。微调平均EF1.112、冻结1.016、相似性1.083；固定主种子内部EF1.062。用于方法选择，属于内部开发评价。
- 外部回顾：未参与本项目监督训练和方法选择的WO2024028364A1 Table10，61项53强/8弱。主模型12/13、EF1.062、AUC0.646；相似性10/13、EF0.885、AUC0.401。两个预定种子13/13；连接合并60项主模型11/12、参照10/12。结果限于该单一专利系列。
- 应用：100000条目录记录→82883独立图→固定10项提名。候选活性与功能方向未知。MD仅对2项候选及已知对照做短程姿势/接触分析。

## 范围与限制

适合现有公开GPR84实验语境下的探索性强效排序与候选假设构建。训练来源/测量条件差异、种子敏感性、分布外结构与骨架转换均可能影响排序。15–43重原子和元素条件来自训练覆盖，不是已验证的适用域。四类参照骨架不同只限已取得范围。

外部评价为标签已知的回顾分析，模型与规则在评分前固定；盲测、前瞻实验及正式预注册尚未开展。无标签预训练语料与外部分子的逐项重叠仍未核清。外部61项专利分子与10项未知候选是不同集合，后者尚无GPR84功能实验结果。弱效类别仅表示实测IC50位于阈值较弱一侧，功能方向由原实验语境确定。对接与短程MD描述当前结构模型中的姿势和接触；候选拮抗效力、选择性、安全性及筛选收益仍需实验评价。

## 核验与资源

原三个正式模型保存后训练单位预测精确回读；本包再次回放每模型固定16个训练样本与10项候选（允许1e-5浮点尾差），同时回读全库排名及提名。真实核验记录见`logs/package_validation_v1/`。GPU为RTX5060Ti 16GB，正式拟合约207秒、全量筛选约864秒；随硬件与环境而变。
